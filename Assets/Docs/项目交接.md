- 主题：涌现；参考《婆罗洲的红珍珠》。
- 策划当前提案：古堡多个房间设有录音设备；设备老化、延迟造成时空错位，玩家根据录音内容与声音，推断真实发生时间并匹配房间。
- 希望播放录音时呈现水波式声纹粒子；具体表现待定。
- 正式文案、美术、时间判定方式与通关条件待策划确定。
