## 当前工程

- Unity 2022.3.62f3、URP 14.0.12，不升级依赖。TMP 使用已安装 3.0.7 的基础资源及现有中文字体。
- 入口 `Assets/Castle/Scenes/CastlePrototype.unity`，Build Settings 只包含有效原型场景。
- 第一版为完整独立示例案件：邀请、地图领取/补领、房间磁带引导、现场录音、中央导入、六类判定、三卡排序、推论与可重播演出。不是正式案件剧情。
- 英文代码命名，玩家文案和必要注释使用中文。新实现位于 `Assets/Castle/Scripts/V2/`，按 Content、Configuration、Session、Gameplay、UI、Diagnostics 分类，不再走旧固定身份题、声音传播联合验证或双结局。

## 内容和模块边界

- `ContentDatabase / CsvContent / ContentValidator`：六表解析和运行时内容；编辑器 `ContentImporter` 发布有效数据库，支持 Plot 单独导入。
- `SessionService`：会话、移动、世界时间、读档入口；`EventService`：窗口、事件队列、Plan B、对白、结算。
- `InventoryService`：稳定 ID 内容收录、链接领取、实例化磁带；`RecordingService`：现场收录、增量导入、权限、刻录、共享游标和校正显示。
- `PuzzleService`：锚点、定位、校时、路径、排序和推论；成功先保存 PendingPuzzle，奖励结算才写入 Solved 和设备认知。
- `SaveService`：独立 `castle-save-v2.json`，临时文件 + File.Replace + .bak；v1 原样保留，不迁移布尔进度。不兼容 v2 拒绝覆盖。
- `PrototypeUi / UiFactory / LinkHandler`：uGUI 页面、TMP 链接、弹窗、滚动、播放器、地图标签和时间线交换；播放及滑动只更新已有组件。页面壳 Prefab 位于 Resources/Castle/Prefabs，具体布局目前由页面工厂生成。
- 策划六表在 `Content/CSV/`，Inspector 配置在 `Resources/Castle/`。导入方式见 `Content/README.md`。

副程接手时可独立扩展内容导入/校验、规则服务或页面表现；共享存档字段和动作接口改动先协调。不要在页面中硬编码新案件答案，不要两人同时改同一场景/Prefab。

## 已知边界

正式 Plot、人物事实、正确顺序、结局、美术和声音仍待策划提供。当前图像沿用旧网页素材，地图图内仍带旧房间名/装饰 UI，逻辑地点由 MapConfig 决定；正式版需要替换干净地图底图。人物卡有配置接口，当前访客头像用文字占位。

声音文字化及合成提示音可运行，无正式完整配音；波形为共享游标驱动的示意效果，不是音频频谱分析。时间线支持拖放和选择槽位/交换卡片；路径支持拖标签或点击地图点位，跨楼层保留。拖动仅淡化原卡，不是最终跟随动画和美术成品。

静态校验识别格式、引用、Plan B 环、明显依赖死锁，不能替代正式案件所有多日消耗路线的人工验证。实际验证结果及 18 条映射见 `第一版验收记录.md`。
