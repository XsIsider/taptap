# 协作与同步

- 开始工作先读项目交接与根目录 `功能与UI实现说明.md`，检查 Git 状态并保留已有修改。
- 同一场景或 Prefab 同时只由一人编辑。共享数据接口变动先与调用方协调。
- 本任务在用户指定的 `prototype_revised` 修改。不要自动切换或合并另一套表配置分支。
- 仅实现已确认规则；当前依据最新双层地图包 SourceData/V24TwoFloors、V2.4 UI流程及用户确认（包括全局BGM）。SourceData/V24、V24MapRevision及根说明历史章节不再作为运行依据。原包测试剧情和占位素材继续明确标注，后续表更新先检查冲突再接入。
- 修改功能、接口、场景绑定或操作方式时，必须同步根说明文档与项目交接，并与资源及 .meta 一起交付。
- 使用普通提交；不擅自强推、重置工作区或改写已推送历史。
- 交付说明实际编译 / 测试结果、未验证项与待接入内容。Git 是同步途径，文档不会自动上传飞书。
